**Part C: MDM-only-on-index baseline (D-09)**

Cannot use PortfolioEngine (no stock fills for an index). Compute a simple NAV:
1. Load `data/vnindex.csv` — read with pandas, filter to PERIOD.
2. Load MDM gate from `precompute_static` (already cached from Part A).
3. Iterate daily: if MDM state == "BUY", NAV tracks index return; if "SELL" or "CASH", NAV is flat (in cash).
4. Compute metrics manually using same formulas as `_compute_metrics`:
   - CAGR = (final_nav / 1.0) ^ (1/n_years) - 1
   - Sharpe_rf3 = (CAGR - 0.03) / (daily_returns.std() * sqrt(252))
   - MaxDD = min(drawdown from peak)

Store as `mdm_only_index` in baselines output.
