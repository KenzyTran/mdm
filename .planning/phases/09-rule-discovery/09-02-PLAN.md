2. **`extract_rules(tree, feature_names, class_names)`** returns `list[str]`:
   - Walk `tree.tree_` recursively per research Pattern 3
   - At each internal node: get feature name via `feature_names[tree_.feature[node]]`, threshold via `tree_.threshold[node]`
   - For boolean features (threshold ~0.5): simplify `feature > 0.5000` to just `feature` and `feature <= 0.5000` to `NOT feature`. Detect boolean by checking if threshold is between 0.4 and 0.6.
   - At leaf nodes: compute `confidence = counts[predicted_class_idx] / total`, get `class_name = class_names[predicted_class_idx]`
   - Format: `"{class_name} when {conditions}: {confidence:.0%} confidence (N={total})"`
   - Per D-04: matches DISC-03 requirement format
   - If conditions list is empty (root is leaf): use `"always"` as condition string
   - Return list of all leaf rules
