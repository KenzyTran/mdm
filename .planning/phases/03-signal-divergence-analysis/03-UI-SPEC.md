# Phase 3 — UI Design Contract

> Visual and interaction contract for matplotlib charts and Jupyter notebook. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **Note:** This phase produces matplotlib visualizations and text reports, not a web UI. The design contract specifies chart styling, color mapping, typography, and layout for `analysis/signal_divergence.py` (PNG output) and `notebooks/signal_overlay.ipynb` (interactive exploration).

## Figure Layout (D-08)

Three-panel vertical layout using `matplotlib.gridspec.GridSpec`.

| Panel | Height Ratio | Content | Y-Axis |
|-------|-------------|---------|--------|
| Price | 4 | NASDAQ close price line | Price (USD) |
| Published signals | 1 | Horizontal color-coded track | None (categorical) |
| Model signals | 1 | Horizontal color-coded track | None (categorical) |

```
GridSpec(3, 1, height_ratios=[4, 1, 1], hspace=0.05)
```

| Property | Value |
|----------|-------|
| Figure size | 20 x 10 inches |
| DPI (PNG export) | 150 |
| DPI (notebook inline) | 100 |
| Price line color | `#1f1f1f` (near-black) |
| Price line width | 0.8pt |
| X-axis sharing | All three panels share x-axis via `sharex` |
| X-axis labels | Bottom panel only; `mdates.ConciseDateFormatter` with `AutoDateLocator` |
| Y-axis grid | Price panel only, light gray `#e0e0e0`, alpha 0.5 |
| Panel labels | Left-side y-axis label: "NASDAQ", "Published", "Model" at font size 10, weight 600 |
| Legend | None (color key in figure title or annotation box instead) |

Declared values (matplotlib uses points/inches, not pixels):

| Token | Value | Usage |
|-------|-------|-------|
| hspace | 0.05 (ratio) | Gap between GridSpec panels |

## Color

### Signal Colors (D-08)

| Signal | Hex | RGB | Usage |
|--------|-----|-----|-------|
| Buy | `#2ca02c` | (44, 160, 44) | Green fill in signal tracks |
| Sell | `#d62728` | (215, 39, 40) | Red fill in signal tracks |
| Cash | `#7f7f7f` | (127, 127, 127) | Gray fill in signal tracks |

These are matplotlib tableau10 defaults for green and red, ensuring accessibility against white background.

### Signal Track Rendering

Use `ax.fill_between()` with `step='post'` to render each signal state as a solid color band. Map the signal string to a numeric value for fill_between, then apply facecolor per segment. Alternative: iterate signal periods and use `ax.axvspan()` per period with the signal color at `alpha=1.0`.

Signal track alpha: 0.7 (slightly transparent to soften visual weight).

### Divergence Shading (D-09)

| Element | Hex | Alpha | Usage |
|---------|-----|-------|-------|
| Divergence zone | `#d62728` | 0.12 | Light red/pink vertical bands on price panel where published != model |

Use `ax.axvspan(start_date, end_date, alpha=0.12, color='#d62728', linewidth=0)` for each contiguous divergence period.

### Chart Background

| Element | Value |
|---------|-------|
| Figure background | `#ffffff` (white) |
| Axes background | `#ffffff` (white) |
| Grid color | `#e0e0e0` at alpha 0.5 |
| Spine color | `#cccccc` |
| Spine visibility | Left + bottom only; top + right hidden |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Figure title | `"MDM Classic vs Published Signals — NASDAQ {start_year}-{end_year}"` |
| Annotation box | `"Match rate: {rate}% | Divergences: {count} ({threshold}T / {timing}Ti / {structural}S / {irreproducible}I)"` |
| Published track label | `"Published"` |
| Model track label | `"Model (Classic)"` |
| Color key (in annotation or subtitle) | `"Green=Buy  Red=Sell  Gray=Cash  Pink bands=Divergence"` |
| Empty state (no published signals in range) | `"No published signals found in date range {start}-{end}. Verify data/signals/nasdaq_signals.csv covers this period."` |
| Empty state (engine produces no signals) | `"MDM engine produced no signal transitions. Check NASDAQ data coverage and indicator warmup period (need 2+ years before comparison window)."` |
| Error state (data load failure) | `"Failed to load {source}: {error}. Ensure file exists and date range is valid."` |
| Divergence summary heading | `"Signal Divergence Report — MDM Classic vs Published NASDAQ Signals"` |
| Summary section: overview | `"Period: {start} to {end} | Published signals: {n} | Model signals: {n} | Match rate: {rate}%"` |
| Summary section: by type | `"Divergences by type:\n  THRESHOLD:      {n} ({pct}%)\n  TIMING:         {n} ({pct}%)\n  STRUCTURAL:     {n} ({pct}%)\n  IRREPRODUCIBLE: {n} ({pct}%)"` |
| Summary section: worst periods | `"Longest divergence streak: {n} days ({start} to {end})"` |
| CSV header row | `"date,published_signal,model_signal,divergence_type,context"` |

## Notebook Interaction Contract

The Jupyter notebook (`notebooks/signal_overlay.ipynb`) provides interactive exploration.

| Feature | Implementation |
|---------|---------------|
| Date range filtering | Variables `start_date` and `end_date` at top of notebook; re-run cells to zoom |
| Signal type filtering | Optional filter to show only divergences of a specific type |
| Inline display | `%matplotlib inline` with `figsize=(18, 9)` for notebook-width charts |
| Cell structure | (1) Imports + config, (2) Load data, (3) Run engine + extract signals, (4) Compare, (5) Summary stats, (6) Full overlay chart, (7) Zoom to specific divergence periods |
