## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug, pre-existing] evaluate_exits had a second MDM SELL dispatch that bypassed retention logic**

- **Found during:** Human review between Task 1 (plan 01) and checkpoint approval
- **Issue:** `evaluate_exits` had its own MDM SELL dispatch that fired for ALL positions when `mdm_state == "SELL"`, including retained positions. This bypassed the partial liquidation logic — all positions were still closed, just via a different code path. This produced buggy OOS results: mdm_sell exits=0 (positions closed before the SELL block ran), MaxDD=-56.45%, CAGR=16.75% (positions held open past SELL by race condition).
- **Fix:** Removed the MDM SELL dispatch from `evaluate_exits`. Engine section (3) is now the sole handler.
- **Files modified:** `strategies/portfolio/engine.py`
- **Commit:** `d218ce3` — "fix(999.1-01): remove MDM SELL dispatch from evaluate_exits"
- **Verification:** All 69/69 portfolio tests pass after fix; OOS shows 5 mdm_sell exits (correct partial liquidation)
