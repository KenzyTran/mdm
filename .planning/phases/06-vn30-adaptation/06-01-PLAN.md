  <action>
    Create `strategies/mdm_v2/vn30_filters.py` with these functions (per D-03):

    1. `add_limit_day_column(df: pd.DataFrame) -> pd.DataFrame`:
       - Compute prev_close = df['close'].shift(1)
       - high_pct = (df['high'] - prev_close) / prev_close
       - low_pct = (df['low'] - prev_close) / prev_close
       - is_limit_day = (high_pct >= 0.065) | (low_pct <= -0.065)
       - Per D-01: column is informational only, signals are NOT suppressed
       - Per D-02: FTD signals on limit-up days remain valid
       - Drop temp columns (high_pct, low_pct), keep prev_close if not already present
       - Return df.copy() with is_limit_day column added

    2. `add_expiry_day_column(df: pd.DataFrame) -> pd.DataFrame`:
       - Per D-06: Compute 3rd Thursday of each month algorithmically
       - For each unique (year, month) in df['date'], compute the 3rd Thursday: weekday==3 (Thursday) and day in range 15-21
       - Per Pitfall 1 (holiday collision): if computed 3rd Thursday is NOT in df['date'], use the latest trading day in df before that date in the same month
       - Set is_expiry_day=True for matching rows, False otherwise
       - Return df.copy() with is_expiry_day column added

    3. `suppress_dd_on_expiry(df: pd.DataFrame) -> pd.DataFrame`:
       - Per D-05: Set volume_up=False on rows where is_expiry_day==True
       - Guard: only apply if 'is_expiry_day' column exists (per Pitfall 5: NASDAQ runs without this column)
       - Return df.copy() with volume_up overridden on expiry days

    4. `apply_vn30_filters(df: pd.DataFrame) -> pd.DataFrame`:
       - Pipeline: add_limit_day_column -> add_expiry_day_column
       - Does NOT call suppress_dd_on_expiry (that runs after engine indicator computation)
       - Return df with both columns added

    Create `tests/test_vn30_filters.py` with pytest tests matching the behavior specifications above. Use synthetic DataFrames (5-10 rows) with known dates and prices. Import from `strategies.mdm_v2.vn30_filters`.
