**1. Verdict enum (per D-07):**
```python
from enum import Enum
class Verdict(Enum):
    CONFIRM = "CONFIRM"
    VETO = "VETO"
    OVERRIDE = "OVERRIDE"
```

**2. FilterConfig dataclass (per D-11, D-03, D-04):**
- Fields with defaults: `ema55_enabled: bool = True`, `macd_enabled: bool = True`, `ema9_21_enabled: bool = True`, `ma200_enabled: bool = False`, `ema9_enabled: bool = False`, `macd_signal_enabled: bool = False`, `majority_threshold: float = 0.67`
- `__post_init__`: assert `0.0 < majority_threshold <= 1.0`. Count active conditions via `active_count()` method. If active > 3, issue `warnings.warn(f"FilterConfig has {active} active conditions. Max 2-3 recommended to avoid overfitting (D-04).")`
- `active_count() -> int`: returns sum of all 6 boolean toggle fields

**3. IndicatorFilter class (per D-02, D-05, D-06, D-07, D-13):**
- `__init__(self, config: FilterConfig = None)`: stores `self.config = config or FilterConfig()`
- 6 static boolean condition methods, each taking a pandas Series `row` and returning `bool`. Each handles NaN by checking `pd.notna()` before comparison, returning False if NaN:
  - `close_above_ema55(row) -> bool`: `pd.notna(row['ema55']) and row['close'] > row['ema55']`
  - `macd_histogram_positive(row) -> bool`: `pd.notna(row['macd_histogram']) and row['macd_histogram'] > 0`
  - `ema9_above_ema21(row) -> bool`: `pd.notna(row['ema9']) and pd.notna(row['ema21']) and row['ema9'] > row['ema21']`
  - `close_above_ma200(row) -> bool`: `pd.notna(row['ma200']) and row['close'] > row['ma200']`
  - `close_above_ema9(row) -> bool`: `pd.notna(row['ema9']) and row['close'] > row['ema9']`
  - `macd_above_signal(row) -> bool`: `pd.notna(row['macd']) and pd.notna(row['macd_signal']) and row['macd'] > row['macd_signal']`

- `_get_bullish_votes(self, row) -> list[bool]`: Returns list of condition results for ENABLED conditions only. Maps: ema55_enabled -> close_above_ema55(row), macd_enabled -> macd_histogram_positive(row), ema9_21_enabled -> ema9_above_ema21(row), ma200_enabled -> close_above_ma200(row), ema9_enabled -> close_above_ema9(row), macd_signal_enabled -> macd_above_signal(row).

- `_get_bearish_votes(self, row) -> list[bool]` (per D-06): Returns list of INVERTED condition results for enabled conditions. Bearish = close BELOW ema55, macd histogram NEGATIVE, ema9 BELOW ema21, etc. Implementation: for each enabled condition, return the negation of the bullish condition. E.g., ema55_enabled -> `not close_above_ema55(row)` BUT must also handle NaN (if NaN, bearish vote = False, not True). Correct logic: `pd.notna(row['ema55']) and row['close'] < row['ema55']` (not just `not close_above_ema55(row)` which would return True on NaN).

  Bearish condition implementations:
  - ema55: `pd.notna(row['ema55']) and row['close'] < row['ema55']`
  - macd: `pd.notna(row['macd_histogram']) and row['macd_histogram'] < 0`
  - ema9_21: `pd.notna(row['ema9']) and pd.notna(row['ema21']) and row['ema9'] < row['ema21']`
  - ma200: `pd.notna(row['ma200']) and row['close'] < row['ma200']`
  - ema9: `pd.notna(row['ema9']) and row['close'] < row['ema9']`
  - macd_signal: `pd.notna(row['macd']) and pd.notna(row['macd_signal']) and row['macd'] < row['macd_signal']`

- `evaluate(self, row, proposal: str, current_state=None) -> Verdict` (per D-05, D-06, D-07):
  - If `proposal == "BUY"`: `conditions = self._get_bullish_votes(row)`
  - If `proposal in ("SELL", "CASH")`: `conditions = self._get_bearish_votes(row)`
  - Else: return `Verdict.CONFIRM`
  - If `len(conditions) == 0`: return `Verdict.CONFIRM`
  - `agree_count = sum(conditions)`, `agree_ratio = agree_count / len(conditions)`
  - If `agree_ratio == 0.0 and len(conditions) >= 3`: return `Verdict.OVERRIDE` (require minimum 3 active for override per RESEARCH.md recommendation)
  - If `agree_ratio >= self.config.majority_threshold`: return `Verdict.CONFIRM`
  - Else: return `Verdict.VETO`

Use Google-style docstrings with Args/Returns on all public methods. Use `import pandas as pd` for `pd.notna`. Use `import warnings` for FilterConfig.
