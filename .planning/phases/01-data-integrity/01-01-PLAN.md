    ```python
    class DataLoader:
        COLUMN_MAPS = {
            'nasdaq': {
                'tradingdate': 'date', 'openprice': 'open', 'closeprice': 'close',
                'highestprice': 'high', 'lowestprice': 'low', 'totalvol': 'volume',
            },
            'sp500': {
                'tradingdate': 'date', 'openprice': 'open', 'closeprice': 'close',
                'highestprice': 'high', 'lowestprice': 'low', 'totalvol': 'volume',
            },
            'vn30': {
                'tradingdate': 'date', 'openindex': 'open', 'closeindex': 'close',
                'highestindex': 'high', 'lowestindex': 'low', 'totalvol': 'volume',
            },
        }
        FILE_PATHS = {
            'nasdaq': 'data/NASDAQ.csv',
            'sp500': 'data/s&p500.csv',
            'vn30': 'data/vn30.csv',
        }
        US_MARKETS = {'nasdaq', 'sp500'}
        OHLC_COLS = ['open', 'high', 'low', 'close']
        OUTPUT_COLS = ['date', 'open', 'high', 'low', 'close', 'volume']
    ```

    Constructor: `def __init__(self, market: str, data_dir: Optional[str] = None)` -- validates market is in COLUMN_MAPS keys, stores market and data_dir (defaults to Path('.')).

    Load method: `def load(self, start_date: str = None, end_date: str = None) -> pd.DataFrame`:
    1. `pd.read_csv(filepath)` to load raw CSV
    2. `df.rename(columns=col_map)` using market-specific mapping (per D-04)
    3. Strip quotes from date column: `df['date'].str.strip('"')`
    4. `pd.to_datetime(df['date'], format='mixed')` then `.dt.normalize()` (per existing pattern)
    5. `pd.to_numeric(col, errors='coerce')` for OHLC + volume columns
    6. For US markets only (per D-01, D-02, D-03): divide OHLC columns by 1000.0. Do NOT divide volume.
    7. Filter by start_date/end_date if provided
    8. `df.sort_values('date').reset_index(drop=True)` (CSVs are newest-first)
    9. `df.dropna(subset=OHLC_COLS + ['volume'])`
    10. Return `df[OUTPUT_COLS]` (per D-05)
