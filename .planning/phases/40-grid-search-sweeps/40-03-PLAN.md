MDMV2Config validation guard (config.py lines 88-96): when `refined_dd_enabled=True`, `__post_init__` asserts:
- `refined_dd_large_drop < 0`
- `refined_dd_small_drop < 0`
- `refined_dd_large_drop <= refined_dd_small_drop` (more negative = larger drop -- ALL grid pairs satisfy this since every large in {-0.005..-0.010} is <= every small in {-0.003..-0.005})
- `0 < refined_dd_small_vol_percentile <= 100`
- `refined_dd_small_vol_lookback > 0`

The grid is pre-validated: all 18 (large_drop, small_drop) combinations satisfy `large <= small` because the max large (-0.005) equals the max small (-0.005) only in the corner case where both are -0.005, and then the assertion `large <= small` holds by equality. Confirmed: -0.005 <= -0.003, -0.005 <= -0.004, -0.005 <= -0.005; and every other large is more negative. No construction will raise.
