**Function 1: `score_predictions(snapshot, clf, feature_cols)`** (per D-01, D-03, D-08)
- Extract `X = snapshot[feature_cols].values` and `y_true = snapshot['signal'].values`
- `y_pred = clf.predict(X)` (per D-08: use sklearn predict directly)
- `y_proba = clf.predict_proba(X)` (per D-08)
- `cm = confusion_matrix(y_true, y_pred, labels=CLASS_NAMES)`
- `report = classification_report(y_true, y_pred, labels=CLASS_NAMES, output_dict=True, zero_division=0)`
- `accuracy = (y_true == y_pred).mean()`
- Return dict: `{'y_true': y_true, 'y_pred': y_pred, 'y_proba': y_proba, 'confusion_matrix': cm, 'classification_report': report, 'accuracy': float(accuracy)}`

**Function 2: `filter_high_confidence(results, threshold=0.70)`** (per D-02)
- `max_proba = results['y_proba'].max(axis=1)`
- `mask = max_proba >= threshold`
- If `mask.sum() == 0`: return dict with empty arrays and note
- Filter `y_true`, `y_pred`, `y_proba` by mask
- Recompute `confusion_matrix` and `classification_report` on filtered subset
- Return same-shaped dict as `score_predictions` plus `'n_total'` and `'n_high_conf'` keys

**Function 3: `cross_era_validation(snapshot, feature_cols, max_depth=4)`** (per D-04, D-05, D-09)
- Split snapshot: `pre, post = split_by_era(snapshot)`
- Train era-specific trees per D-09 (retrain, no saved models):
  - `pre_clf, pre_cv, pre_feat = train_era_tree(pre, feature_cols, max_depth=max_depth)`
  - `post_clf, post_cv, post_feat = train_era_tree(post, feature_cols, max_depth=max_depth)`
- Extract features/labels for each era:
  - `X_pre, y_pre = pre[feature_cols].values, pre['signal'].values`
  - `X_post, y_post = post[feature_cols].values, post['signal'].values`
- Same-era accuracy: `pre_same = (pre_clf.predict(X_pre) == y_pre).mean()`
- Same-era accuracy: `post_same = (post_clf.predict(X_post) == y_post).mean()`
- Cross-era: `pre_on_post = (pre_clf.predict(X_post) == y_post).mean()`
- Cross-era: `post_on_pre = (post_clf.predict(X_pre) == y_pre).mean()`
- Degradation per D-05: `pre_degradation = pre_same - pre_on_post`; `post_degradation = post_same - post_on_pre`
- Return dict with all 6 float values: `pre_same_era`, `post_same_era`, `pre_on_post`, `post_on_pre`, `pre_degradation`, `post_degradation`
- Also include `pre_clf`, `post_clf` in return for Plan 02 dashboard use

**Function 4: `generate_validation_report(snapshot, feature_cols, confidence_threshold=0.70)`**
- Calls `split_by_era`, `train_era_tree` for both eras (per D-09)
- Calls `score_predictions` for pre-era tree on pre data, post-era tree on post data, and each tree on full data
- Calls `filter_high_confidence` on full-data results
- Calls `cross_era_validation`
- Builds markdown report string with sections:
  - "## Overall Match Rate" -- full accuracy, per-type precision/recall table
  - "## Confusion Matrix" -- formatted as markdown table
  - "## High-Confidence Subset (>= {threshold}%)" -- count and metrics
  - "## Era-Based Cross-Validation" -- same-era vs cross-era table with degradation delta
  - "## Structural Change Quantification" -- narrative framing per D-05
- Returns `(report_text, results_dict)` where results_dict has all computed data
