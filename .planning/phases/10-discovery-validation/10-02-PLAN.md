Add function `generate_dashboard(snapshot, feature_cols, output_path='output/discovery_dashboard.png', max_depth=4)`:

1. Split data: `pre, post = split_by_era(snapshot)`
2. Train trees per D-09: `pre_clf, _, _ = train_era_tree(pre, feature_cols, max_depth=max_depth)` and same for post
3. Generate predictions for each era:
   - `pre_preds = pre_clf.predict(pre[feature_cols].values)`
   - `post_preds = post_clf.predict(post[feature_cols].values)`
4. Create figure: `fig, (ax_pre, ax_post) = plt.subplots(2, 1, figsize=(18, 14), sharex=False)`
5. Color map per D-06: `colors = {'Buy': '#2ca02c', 'Sell': '#d62728', 'Cash': '#7f7f7f'}`
6. For each `(ax, era_df, era_preds, era_name)` in `[(ax_pre, pre, pre_preds, 'Pre-2019'), (ax_post, post, post_preds, 'Post-2019')]`:
   - Plot NASDAQ price: `ax.plot(era_df['date'], era_df['close'], 'k-', linewidth=0.8, alpha=0.6, label='NASDAQ')`
   - Compute `y_offset_up = era_df['close'].max() * 0.015` and `y_offset_down = era_df['close'].max() * 0.015`
   - Published signals (markers above price per D-06 "top row"):
     - For each signal_type in CLASS_NAMES, marker in `['^', 'v', 'D']`:
       - `mask = era_df['signal'].values == signal_type`
       - `ax.scatter(era_df.loc[mask, 'date'], era_df.loc[mask, 'close'] + y_offset_up, marker=marker, c=colors[signal_type], s=60, alpha=0.8, zorder=5, label=f'Published {signal_type}')`
   - Discovered signals (markers below price per D-06 "bottom row"):
     - `pred_series = pd.Series(era_preds, index=era_df.index)`
     - For each signal_type, marker in `['o', 's', 'x']`:
       - `mask = pred_series == signal_type`
       - `ax.scatter(era_df.loc[mask, 'date'], era_df.loc[mask, 'close'] - y_offset_down, marker=marker, c=colors[signal_type], s=40, alpha=0.6, zorder=4, label=f'Discovered {signal_type}')`
   - Highlight divergences: where `era_df['signal'].values != era_preds`, draw vertical gray lines (alpha=0.2) from price -offset to price +offset
   - Set title: `ax.set_title(f'{era_name} Era: Published vs Discovered Signals', fontsize=13)`
   - Add legend with `ax.legend(loc='upper left', fontsize=8, ncol=3)`
   - Set y-label: `ax.set_ylabel('NASDAQ Index')`
7. `fig.suptitle('Discovery Validation: Published vs Rule-Based Signals', fontsize=15, fontweight='bold')`
8. `plt.tight_layout(rect=[0, 0, 1, 0.96])`
9. Ensure output directory: `os.makedirs(os.path.dirname(output_path), exist_ok=True)`
10. `fig.savefig(output_path, dpi=150, bbox_inches='tight')`
11. `plt.close(fig)`
12. Return `output_path`
