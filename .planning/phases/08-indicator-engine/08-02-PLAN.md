  <action>
    Create core/feature_snapshot.py with two functions:

    1. `snap_to_trading_day(signal_date: pd.Timestamp, trading_dates: pd.DatetimeIndex, max_lookback: int = 5) -> pd.Timestamp`:
       - If signal_date is in trading_dates, return it unchanged
       - Otherwise search backward day by day (up to max_lookback days) for the nearest prior trading day
       - If no match found within max_lookback, return pd.NaT
       - This handles the 10 weekend signal dates by snapping to Friday (per research recommendation)

    2. `extract_feature_snapshot(indicators_df: pd.DataFrame, signals_df: pd.DataFrame) -> pd.DataFrame`:
       - Input: indicators_df from build_indicator_dataframe() with date column, signals_df from load_signal_fixture() with date and signal columns
       - Step 1: Normalize both date columns to datetime64 (ensure no timezone issues)
       - Step 2: Get trading_dates as DatetimeIndex from indicators_df['date']
       - Step 3: For each signal date, apply snap_to_trading_day to get the lookup_date
       - Step 4: Create a mapping DataFrame with columns [original_date, lookup_date, signal, gain_loss_pct]
       - Step 5: Merge mapping with indicators_df on lookup_date == date (left join)
       - Step 6: Replace the date column with original_date (preserve signal dates, not snapped dates)
       - Step 7: Add 8 derived boolean features:
         - `ema9_above_ema21` = ema9 > ema21
         - `ema21_above_ema55` = ema21 > ema55
         - `close_above_ma200` = close > ma200
         - `close_above_ema9` = close > ema9
         - `close_above_ema21` = close > ema21
         - `close_above_ema55` = close > ema55
         - `macd_histogram_positive` = macd_histogram > 0
         - `macd_above_signal` = macd > macd_signal
       - Step 8: Return the DataFrame sorted by date

    Then create tests/test_feature_snapshot.py with all tests from behavior section. Use small synthetic DataFrames (20-50 rows of fake OHLCV with known indicator values) for unit tests.

    - For rows where ma200 is NaN (before warmup), close_above_ma200 should be False (use `.fillna(False)` before bool cast)
    - Include docstrings on both functions with Args/Returns sections
