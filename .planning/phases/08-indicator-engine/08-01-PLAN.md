  <action>
    Create core/indicators.py with these pure functions (NOT a class -- use module-level functions per research recommendation):

    1. `compute_ema(series: pd.Series, span: int) -> pd.Series`:
       - Return `series.ewm(span=span, adjust=False).mean()`
       - CRITICAL: always `adjust=False` to match TradingView/StockCharts (per IND-01)

    2. `compute_sma(series: pd.Series, window: int) -> pd.Series`:
       - Return `series.rolling(window=window, min_periods=window).mean()`
       - CRITICAL: `min_periods=window` NOT `min_periods=1` (per IND-02, avoids partial window averages)

    3. `compute_macd(close: pd.Series, fast: int = 12, slow: int = 26, signal: int = 9) -> pd.DataFrame`:
       - ema_fast = close.ewm(span=fast, adjust=False).mean()
       - ema_slow = close.ewm(span=slow, adjust=False).mean()
       - macd_line = ema_fast - ema_slow
       - signal_line = macd_line.ewm(span=signal, adjust=False).mean()
       - histogram = macd_line - signal_line
       - Return DataFrame with columns: macd, macd_signal, macd_histogram (per IND-03)

    4. `compute_heikin_ashi(df: pd.DataFrame) -> pd.DataFrame`:
       - Input has columns: open, high, low, close
       - ha_close = (open + high + low + close) / 4
       - ha_open[0] = (open[0] + close[0]) / 2
       - ha_open[i] = (ha_open[i-1] + ha_close[i-1]) / 2 (loop required -- recursive dependency)
       - ha_high = max(high, ha_open, ha_close) per row
       - ha_low = min(low, ha_open, ha_close) per row
       - Return DataFrame with columns: ha_open, ha_high, ha_low, ha_close

    5. `compute_heikin_ashi_smoothed(df: pd.DataFrame, period: int = 55) -> pd.DataFrame`:
       - Stage 1: Smooth each of open/high/low/close with EMA(period) using adjust=False
       - Stage 2: Pass smoothed DataFrame to compute_heikin_ashi()
       - Return DataFrame with columns: ha_open, ha_high, ha_low, ha_close (per IND-04)

    6. `build_indicator_dataframe(ohlcv: pd.DataFrame) -> pd.DataFrame`:
       - Copy input DataFrame
       - Add ema9, ema21, ema55 from compute_ema on close column
       - Add ma200 from compute_sma on close column
       - Add macd, macd_signal, macd_histogram from compute_macd on close column
       - Add ha_smooth_open, ha_smooth_high, ha_smooth_low, ha_smooth_close from compute_heikin_ashi_smoothed
       - Return the enriched DataFrame

    Then create tests/test_indicators.py with all tests from the behavior section above. Use small synthetic DataFrames for unit tests (5-20 rows). Use pytest and numpy.testing.assert_allclose for floating point comparison with rtol=1e-6.
