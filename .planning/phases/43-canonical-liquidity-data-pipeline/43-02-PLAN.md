Source citation format rules:
- One primary source per row is the minimum. Multiple sources joined with `; ` when helpful.
- Cite publication + date + short headline/identifier. E.g.:
  - `"Reuters 2022-09-22 SBV raises refinance rate 100bp to 5%"`
  - `"Vietnam News 2023-03-14 SBV cuts discount rate"`
  - `"SBV press release sbv.gov.vn 2020-03-16 Decision 418/QD-NHNN"`
- CSV-escape any internal commas by wrapping the source cell in double-quotes per RFC 4180.
- No URLs required (they rot) — publication + date + headline is sufficient for audit.

D-06 schema freeze:
- 5 columns EXACTLY, in this order: `date, rate_change_pct, new_refinance_rate_pct, direction, source`
- `direction` values: `easing` or `tightening` ONLY (lowercase, no quotes in direction column).
- `neutral` is NOT a stored value — Phase 44 derives it via 90-day decay (D-08).
- Date format: ISO `YYYY-MM-DD`, no quotes needed.
- Numeric columns: bare decimals (e.g., `-0.25`, `1.00`), no quotes.

Event authenticity guardrails (D-07):
- Do NOT invent 2014-2016 or 2024-2025 events to pad the row count. Quick task confirmed SBV held rates steady across most of those years.
- IF during the citation pass a researcher finds a genuinely additional well-sourced event (e.g., a 2024 discount-rate micro-adjustment via a Reuters link), appending it is permitted — but the bar is "verifiable public source with a date and headline" — NOT a blog post or forum rumor.
- When in doubt, omit rather than invent. 12 sourced rows > 15 unverifiable rows.
