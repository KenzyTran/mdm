**Functions to implement:**

1. `build_confusion_matrices(hybrid_results, published_signals) -> dict`:
   - Inner-merge published signals with hybrid results on date
   - Map hybrid `state` column via STATE_TO_SIGNAL to get `predicted`
   - Compute confusion_matrix with `labels=CLASS_NAMES`
   - Compute classification_report with `labels=CLASS_NAMES, output_dict=True, zero_division=0`
   - Split into full (all signals), pre-2019, and post-2019 subsets
   - Return dict with keys: full_cm, full_report, pre2019_cm, pre2019_report, post2019_cm, post2019_report, full_accuracy, pre2019_accuracy, post2019_accuracy, n_matched

2. `build_signal_diagnosis(hybrid_results, published_signals) -> pd.DataFrame`:
   - Inner-merge on date
   - Select columns: date, signal (published), old_state, proposed, verdict, state (rename to final_state)
   - Add `predicted` column (state mapped via STATE_TO_SIGNAL)
   - Add `match` column (published signal == predicted)
   - Add `filter_effect` column: 'helped' if proposed != predicted and predicted matches published, 'hurt' if proposed matches published but predicted doesn't, 'neutral' otherwise
   - Return the diagnosis DataFrame

3. `compute_v2_baseline(df, published_signals) -> dict`:
   - Run `MDMV2Engine(MDMV2Config()).run(df)`
   - Use extract_model_signals + compare_signals against full and post-2019 published signals
   - Return dict with full_match_rate, post2019_match_rate, per_type

4. `define_heldout_split(published_signals) -> dict`:
   - Filter to post-2019 signals
   - Last HELDOUT_COUNT signals = held-out (chronological, no randomness)
   - Rest = tune set
   - Return dict with tune_signals (DataFrame), heldout_signals (DataFrame), heldout_dates (list), tune_count, heldout_count

5. `format_confusion_matrix(cm, class_names) -> str`:
   - Format 3x3 matrix as aligned text table (follow pattern from validate_discovery.py `_format_confusion_matrix`)

6. `generate_report(cm_results, v2_baseline, diagnosis, heldout_split, hybrid_summary) -> str`:
   - Build markdown report string with sections:
     - Overall Accuracy (full 962, pre-2019, post-2019)
     - V2 Baseline Comparison (post-2019 hybrid vs v2, delta)
     - Confusion Matrices (full, post-2019)
     - Per-Type Accuracy from classification_report (precision, recall, f1 for Buy/Cash/Sell)
     - Held-Out Results (tune set accuracy vs held-out accuracy)
     - Filter Effect Summary (count of helped/hurt/neutral from diagnosis)
     - Signal Diagnosis Sample (first 20 rows where filter_effect != 'neutral')

7. `main()`:
   - Step 1: Load NASDAQ data via DataLoader('nasdaq', data_dir=project_root), load published signals from `data/signals/nasdaq_signals_full.csv`
   - Step 2: Run hybrid engine with filter_enabled=True
   - Step 3: Run v2 baseline on same data
   - Step 4: Define held-out split
   - Step 5: Build confusion matrices (full, pre-2019, post-2019, tune-set, held-out set)
   - Step 6: Build signal diagnosis
   - Step 7: Generate report
   - Step 8: Save outputs:
     - `output/hybrid_validation_report.md` (full markdown report)
     - `output/hybrid_signal_diagnosis.csv` (diagnosis DataFrame)
     - `output/hybrid_confusion_matrix.txt` (formatted confusion matrices)
   - Print summary to console with key numbers
