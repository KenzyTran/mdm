  <action>
    Create `analysis/sweep_vn100.py`:

    1. Module docstring referencing BT-02 / Phase 32 SC2 + D-03..D-17. Hard-coded period 2014-01-01..2018-12-31 (D-09).

    2. Module-level constants:
       ```python
       PERIOD = ("2014-01-01", "2018-12-31")
       GRID = {
           "c_yoy":       [0.10, 0.15, 0.20, 0.25],
           "a_cagr":      [0.10, 0.15, 0.20, 0.25],
           "n_proximity": [0.05, 0.10, 0.15, 0.20],
           "hard_stop":   [0.06, 0.07, 0.08, 0.10],
           "slots":       [5, 8, 10],
           "entry_option":["A", "C"],
       }
       OUTPUT_CSV = Path("docs/audits/phase32/sweep_results.csv")
       SANITY_CAGR_THRESHOLD = 3.0  # 300% per D-13 / SC5
       METRIC_COLS = ["CAGR","Sharpe_rf3","MaxDD","MaxDD_duration_days","hit_rate","turnover","total_cost_drag_pct","num_trades","avg_hold_days"]
       ```

    3. `build_grid() -> list[dict]`: itertools.product over GRID values, return list of 1,536 config dicts.

    4. `_worker(args: tuple) -> dict` (top-level for Windows spawn pickling):
       - Unpack `(config_dict, precomputed_path)` — note: precomputed cache is on disk via parquet, workers re-load it (cheap because parquet).
       - Build `CanslimConfig` (override c_yoy, a_cagr, n_proximity; rest = Phase 29 defaults).
       - Build `PortfolioConfig` (override max_slots=config["slots"], hard_stop=config["hard_stop"], entry_mode=config["entry_option"]; rest = Phase 31 defaults).
       - try:
           - `result = run_vn100_backtest(canslim_cfg, portfolio_cfg, config["entry_option"], PERIOD, precomputed=None)` (precomputed re-loads from parquet cache inside _vn100_pipeline)
           - row = {**config, **result["metrics"], "sanity_flag": "OK", "error": ""}
           - if row["CAGR"] > SANITY_CAGR_THRESHOLD: row["sanity_flag"] = "CAGR_TOO_HIGH"
       - except Exception as e:
           - row = {**config, **{k: float("nan") for k in METRIC_COLS}, "sanity_flag": "ERROR", "error": f"{type(e).__name__}: {e}"}
       - return row

    5. `main()`:
       - Print start banner.
       - Trigger `precompute_static(PERIOD)` once in main process to populate parquet cache before fanout (D-05 step 1).
       - grid = build_grid(); assert len(grid) == 1536.
       - Use `multiprocessing.Pool(max(1, cpu_count() - 1))` (D-06).
       - `results = []`; iterate `pool.imap_unordered(_worker, [(cfg, None) for cfg in grid], chunksize=4)` wrapped in `tqdm(total=1536, desc="sweep")` (D-07).
       - Append each row to `results`.
       - Convert to DataFrame with column order: grid params first, then METRIC_COLS, then `sanity_flag, error`.
       - Write to `OUTPUT_CSV` (mkdir parents).
       - Print summary: total configs, successes, errors, flagged.
       - Print warning if any flagged (D-13).

    6. `if __name__ == "__main__": main()`.
