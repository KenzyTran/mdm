  <action>
    Create `analysis/compare_models.py` — standalone script following validate_hybrid.py pattern.

    **Structure:**
    ```python
    """
    Three-Way Model Comparison Dashboard

    Compares pure state machine (v2), pure decision tree, and hybrid MDM
    model accuracy against 962 published signals, with per-type breakdown
    and side-by-side confusion matrices.

    Usage:
        uv run python analysis/compare_models.py
    """
    ```

    **Three models to run:**

    1. **Pure state machine (v2):** Import and run MDMV2Engine with default MDMV2Config on NASDAQ data. Extract model signals via `extract_model_signals()`. Compare against published signals.

    2. **Pure decision tree:** Import DecisionTreeClassifier from sklearn. Load feature snapshots (reuse logic from rule_discovery.py). Train on full dataset with `random_state=42, max_depth=5, min_samples_leaf=10`. Predict signal types from indicator features. Compare predictions against published signal types.

    3. **Hybrid model:** Import and run HybridEngine with `HybridConfig(filter_enabled=True)` (default FilterConfig, ha_smooth_enabled=False). Extract model signals. Compare against published signals.

    **Data loading pattern** (reuse from validate_hybrid.py):
    ```python
    loader = DataLoader()
    df = loader.load_nasdaq()
    published = load_signal_fixture('nasdaq_signals_full')
    ```

    **For decision tree, load feature snapshots:**
    ```python
    from core.feature_snapshot import extract_feature_snapshots
    from core.indicators import build_indicator_dataframe
    indicator_df = build_indicator_dataframe(df)
    features = extract_feature_snapshots(indicator_df, published)
    ```

    **Dashboard output — matplotlib figure with 4 subplots:**

    1. **Top-left: Per-type accuracy bar chart** (3 groups x 3 bars)
       - X-axis: Buy, Cash, Sell
       - Bars: v2 (blue), DT (orange), Hybrid (green)
       - Y-axis: Accuracy 0-1.0
       - Use sklearn classification_report(output_dict=True) to get per-type recall

    2. **Top-right: Overall accuracy comparison**
       - Simple bar chart: 3 bars showing overall accuracy for each model
       - Add text labels on bars with exact percentage

    3. **Bottom row: Three confusion matrix heatmaps** side-by-side
       - Use sklearn confusion_matrix + matplotlib imshow/matshow
       - Annotate cells with counts
       - Titles: "Pure State Machine", "Pure Decision Tree", "Hybrid"

    **Text report output:**
    - Print overall accuracy table to stdout
    - Print per-type breakdown (precision, recall, f1 for each model)
    - Save figure to `output/model_comparison.png`

    **Save chart:**
    ```python
    os.makedirs('output', exist_ok=True)
    fig.savefig('output/model_comparison.png', dpi=150, bbox_inches='tight')
    print(f"Dashboard saved to output/model_comparison.png")
    ```

    **IMPORTANT:**
    - Set `random_state=42` for DecisionTreeClassifier for reproducibility
    - Use `sys.path.insert(0, ...)` at top like other analysis scripts
    - Guard DT prediction: the DT predicts on feature snapshots at signal dates, not daily bars. Map predictions back to signal dates for comparison.
    - Handle the case where DT features may have NaN for early signals (warm-up period) — drop those rows before training/predicting.
