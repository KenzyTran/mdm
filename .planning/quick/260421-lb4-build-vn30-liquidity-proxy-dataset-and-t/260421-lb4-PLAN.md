Step 1. Create `analysis/test_liquidity_correlation.py`:
  - Module docstring: "Test correlation of 5 liquidity proxies with VN30 same-day and 20d-forward returns; split VN30 performance by SBV policy regime; emit markdown verdict report."
  - Constants at top:
      VN30_CSV = Path('data/vn30_price.csv')
      PROXY_CSV = Path('data/vn_liquidity_proxy.csv')
      SBV_CSV = Path('data/sbv_policy_events.csv')
      REPORT_MD = Path('docs/research/liquidity_proxy_correlation.md')
      FWD_WINDOW = 20
      CORR_THRESHOLD = 0.15            # |corr| gate on 20d-forward VN30 returns
      REGIME_CAGR_GAP_PP = 3.0         # percentage points
      REGIME_SHARPE_GAP = 0.15
      TRADING_DAYS = 252
      PROXY_COLS = ['usdvnd_close','dxy_close','tnx_close','vnm_close','eem_close']
  - Function `load_vn30() -> pd.DataFrame`:
      Read `vn30_price.csv`, rename `tradingdate`->`date`, `closeindex`->`close`. Coerce to numeric. Parse date. Sort by date. Filter to date >= 2015-01-01. Compute `ret` = `close.pct_change()`. Compute `ret_fwd20` = `close.pct_change(FWD_WINDOW).shift(-FWD_WINDOW)` (forward return looking 20 bars ahead). Return DataFrame with columns [date, close, ret, ret_fwd20].
  - Function `load_proxies() -> pd.DataFrame`:
      Read `vn_liquidity_proxy.csv`. Parse date. Forward-fill each price column (different markets close on different days). Compute daily returns per proxy: `<col>_ret` = `<col>.pct_change()`. Also compute 20-day rolling z-scores per proxy: `<col>_z20` = `((x - rolling_mean_20) / rolling_std_20)` using `.rolling(20).mean()` / `.rolling(20).std()`. Return DataFrame keyed on date with the original price cols plus `_ret` and `_z20` columns.
  - Function `load_sbv_regime(dates: pd.Series) -> pd.Series`:
      Read `sbv_policy_events.csv`. For each date in `dates`, find the most recent event on-or-before that date (`merge_asof(direction='backward')`). Apply a 90-day decay: regime = event.direction for dates within 90 days of the event; otherwise 'neutral'. Return a Series aligned to dates with values ∈ {'easing','tightening','neutral'}. (Rationale: SBV easing/tightening impulses don't persist forever; a 90d window captures the typical transmission lag without labeling 2018 as "easing" because of a 2015 cut.)
  - Function `compute_correlations(vn30: pd.DataFrame, proxies: pd.DataFrame) -> pd.DataFrame`:
      Merge vn30 (ret, ret_fwd20) with proxies on date (inner join — drop VN30 days when no proxy data exists, e.g., US holidays). For each proxy column, compute:
        * `corr_sameday_ret`: pearson(<col>_ret, vn30.ret)
        * `corr_fwd20_ret`:   pearson(<col>_ret, vn30.ret_fwd20)
        * `corr_sameday_z`:   pearson(<col>_z20, vn30.ret)
        * `corr_fwd20_z`:     pearson(<col>_z20, vn30.ret_fwd20)
      Return as DataFrame indexed by proxy name with 4 columns. Drop rows with NaN before each pearson call (use `.dropna()` on the two aligned series).
  - Function `compute_regime_metrics(vn30: pd.DataFrame, regime: pd.Series) -> pd.DataFrame`:
      For each regime ∈ {'easing','neutral','tightening'}:
        * subset = vn30 where regime matches, with ret not NaN
        * `days` = len(subset)
        * `total_return_pct` = (1 + subset.ret).prod() - 1, times 100
        * `cagr_pct` = ((1 + total_return_pct/100) ** (TRADING_DAYS/days) - 1) * 100  (only if days > 0)
        * `sharpe_rf3` = (subset.ret.mean()*TRADING_DAYS - 0.03) / (subset.ret.std()*sqrt(TRADING_DAYS))
        * `max_dd_pct` = compute running max of cum-return, then min of (cum/running_max - 1) * 100
      Return a DataFrame with rows=regimes, cols=[days, total_return_pct, cagr_pct, sharpe_rf3, max_dd_pct].
  - Function `decide_verdict(corr_df: pd.DataFrame, regime_df: pd.DataFrame) -> Tuple[str, List[str]]`:
      Build list of reasons. Check gate A: any |corr_fwd20_ret| or |corr_fwd20_z| >= CORR_THRESHOLD. Check gate B: among {easing, tightening, neutral} with non-null cagr_pct, (max_cagr - min_cagr) >= REGIME_CAGR_GAP_PP OR (max_sharpe - min_sharpe) >= REGIME_SHARPE_GAP. Verdict = 'GO' if gate A or gate B triggers, else 'NO-GO'. Reasons list cites the specific numbers that fired (or the best-case numbers that missed).
  - Function `write_report(corr_df, regime_df, verdict, reasons) -> None`:
      Ensures `docs/research/` exists. Writes markdown with:
        1. Header `# Liquidity Proxy Correlation with VN30 Returns` + one-paragraph context citing Phase 41 walk-forward degradation motivation.
        2. Section `## Correlation Table` with corr_df rendered as markdown (6-decimal precision, no trailing zeros stripped — use `.to_markdown(floatfmt='.4f')` if tabulate available, else manual markdown via `.to_string()` fallback in a fenced code block).
        3. Section `## SBV Regime Split` with regime_df markdown.
        4. Section `## Decision Gates` listing the two criteria and their numeric outcome.
        5. Section `## Verdict` with the bold verdict (GO or NO-GO) and the reasons list.
        6. Section `## Reproducibility` listing script path, input files, and date range used.
  - Function `main()`: orchestrate load -> compute -> decide -> write -> also print the verdict and one-line summary to stdout.
  - Standard `if __name__ == '__main__': main()` block.

Step 2. Dependency check: `tabulate` is not in pyproject.
