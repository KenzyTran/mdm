## Open risks for Phase 29+

Concrete observations from the live run (2026-04-09):

1. **Massive survivorship bias in `stock_eod`.** 852 / 2936 distinct tickers (29 %) have `max(tradingdate) < 2024-01-01`. Phase 29 must decide explicitly whether the VN100 backtest universe includes delisted names — otherwise reported returns will be inflated.
2. **FLC active, ROS delisted, HVN active.** ROS is the only canonical scandal-delist of the three currently absent from live data. FLC and HVN still trade and need no special handling, but ROS-style names will silently disappear from any naive max(tradingdate)-only universe filter.
3. **13 / 70 VN100 tickers (19 %) have ZERO rows in `is_quarter_nonbank` 2014-2025.** All thirteen — `BVH, BSI, DSE, CTS, FTS, MSB, HCM, EIB, OCB, NAB, VCI, VIX, VND` — are banks, securities firms, or insurance, which live in `is_quarter_bank` / `is_quarter_stock` / `is_quarter_insurance`. Phase 29 fundamentals loader **must** route by sector to avoid silently dropping ~20 % of the VN100.
4. **24 / 70 VN100 tickers (34 %) have <40 / 48 quarters present in `is_quarter_nonbank` 2014-2025.** Tickers with sparse early-period coverage (e.g. recently-listed names) cannot satisfy CANSLIM "8 consecutive quarters of EPS growth" rules in 2014-2018; backtests starting before ~2019 will systematically exclude them.
5. **`is_quarter_nonbank` exposes no `eps` column.** Schema is in Vietnamese (`mack`, `thoigian`, `loi_nhuan_sau_thue_cua_co_dong_cua_cong_ty_me`, …); EPS must be derived from net income ÷ shares-outstanding (or sourced from `ratios_stock`, which is securities-firms-only — only ~40 tickers, so unusable for VN100). **Phase 29 must build an EPS derivation step** before the CANSLIM "C" / "A" criteria can be evaluated.
6. **`stock_foreign_eod` only starts in April 2022.** Earliest first_date across the VN100 is 2022-04-07; median per-ticker row count is 994 days. Any phase 29+ rule that uses foreign-flow features (the "I" in CANSLIM, foreign-buying breakouts, etc.) is **only viable from 2022-04 onward** — backtests covering 2014-2021 will need a fallback or must exclude foreign-flow features entirely.
7. **`stock_eod` global min date is 1861-12-31.** Likely a sentinel / NULL row from upstream ingestion. Loader should clip to a sane lower bound (e.g. 2000-01-01) to avoid outlier dates polluting min/max statistics.
8. **`resolve_eps_publish_date` (DATA-04) executes cleanly on real data** — no schema-shape blockers — but only after we synthesise `yearreport` / `lengthreport` from the raw `thoigian` text. Phase 29 fundamentals loader should perform that parse once at load time and expose canonical `(yearreport, lengthreport)` columns to downstream code.
